# 📚 Research Paper Explainer

A Streamlit + LangChain application that explains popular AI research papers in different styles and lengths using Google's Gemini model.

## Features

- Multiple AI research papers
- Beginner-Friendly / Technical explanations
- Adjustable summary length
- Powered by LangChain Prompt Templates
- Gemini 2.5 Flash integration

## Setup

### Clone Repository

```bash
git clone <repo-url>
cd research-paper-explainer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Add API Key

Create a `.env` file:

```env
GOOGLE_API_KEY=ADD_YOUR_API_KEY_HERE
```

### Run Application

```bash
streamlit run app.py
```

## Tech Stack

- Python
- Streamlit
- LangChain
- Google Gemini
